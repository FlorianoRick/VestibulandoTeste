# Central do Vestibulando

Portal centralizado para acompanhamento de vestibulares, editais, provas, gabaritos, calendário e materiais de estudo.

## Como visualizar localmente

1. Abra a pasta do projeto.
2. Inicie um servidor local simples:
   - `python -m http.server 8000`
3. Acesse: `http://localhost:8000`

## Funcionalidades incluídas

- Dashboard inicial com métricas e busca rápida
- Catálogo de vestibulares por instituição e filtro
- Calendário com eventos e conflitos
- Banco de provas anteriores com links para PDFs e gabaritos
- Conteúdos por disciplina e comparação por vestibular
- Planejamento de estudos e instituições em destaque
- Notícias e atualizações do cenário educacional
